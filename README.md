# my_web

自己紹介と作品集のポートフォリオサイトです。

| ページ | 内容 |
|---|---|
| `index.html` | トップページ |
| `about.html` | 自己紹介 |
| `works.html` | 作品集 |
| `contact.html` | 連絡先 |
| `advancements.html` | マイクラ進捗トラッカー（Java版 26.3） |

デザインは `style.css`（サイト共通）と `advancements.css`（進捗トラッカー用）にまとめています。

進捗トラッカーのアイコンと進捗名は Minecraft のゲームデータをもとにしています。
Minecraft は Mojang Studios の商標です。このサイトは Mojang Studios / Microsoft とは関係のない非公式のファンサイトです。
